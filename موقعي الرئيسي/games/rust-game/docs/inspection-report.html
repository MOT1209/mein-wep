الصفحة الرئيسية تُخدَّم من الكاش دائمًا — أي تحديث مستقبلي لن يصل للاعبين القدامى أبدًا إلا بمسح يدوي. يجب أن تكون الملاحة network-first.

الإصلاح: تبديل الاستراتيجية للملاحة (navigate) إلى network-first مع fallback للكاش، وزيادة CACHE_NAME عند كل تحديث.
